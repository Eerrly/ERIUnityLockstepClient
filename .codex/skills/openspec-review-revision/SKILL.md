# OpenSpec 审查修订流程

## 流程

1. 读取审查反馈。
2. 对照 active change 文档定位问题。
3. 区分阻塞项、建议项和占位项。
4. 只修改对应 OpenSpec 或 AI 工作流文档。
5. 保留不明确功能为 `待补充`。
6. 输出修订摘要。

## 禁止

- 不补写未确认的业务功能。
- 不修改代码。
- 不覆盖现有项目规则。
- 不把其他项目内容粘贴进本项目。
